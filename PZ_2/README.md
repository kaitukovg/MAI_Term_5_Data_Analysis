# Парсер новостей РЭУ категории "Наука"

Программа автоматически собирает новости с сайта Российского экономического университета им. Г. В. Плеханова и сохраняет их в SQLite.

### Как работает

При запуске программа сначала проверяет, есть ли новости в базе данных:
- если база пустая — выполняется первоначальный парсинг страниц с новостями и данные сохраняются в БД;
- если база уже содержит данные — первоначальный парсинг пропускается.

После этого программа регулярно проверяет сайт на появление новых новостей и добавляет их в базу, избегая дубликатов по URL.
